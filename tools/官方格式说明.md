# 官方动画格式说明（BILD v6 / ANIM v4）

> 来源：`tools/official/scripts/buildanimation.py` 头部注释（Klei 官方 Mod Tools，MIT）。
> 本文只做整理，字段顺序以官方脚本为准。

## BILD（build.bin，版本 6）

```text
'BILD'                      4 字节魔数
Version (int)               版本，正常为 6
total symbols (int)         符号数
total frames (int)          总帧数
build name (int, string)    长度前缀的 UTF-8 字符串
num materials (int)         材质数
  material texture name     长度前缀字符串
for each symbol:
  symbol hash (int)         小写符号名的哈希
  num frames (int)
    frame num (int)
    frame duration (int)    手持符号 <=1 会出问题
    bbox x, y, w, h         float ×4
    vb start index (int)
    num verts (int)
num vertices (int)
  x, y, z, u, v, w          float ×6
num hashed strings (int)
  hash (int)
  original string           长度前缀字符串
```

要点：

- **bbox 是符号局部坐标**，不是图集坐标；和 pivot 一起决定图片画在哪
- `duration` 是“这一帧持续多少游戏帧”，不是秒
- 末尾的哈希表用于把 `symbol hash` 还原成名字

## ANIM（anim.bin，版本 4）

```text
'ANIM'                      4 字节魔数
Version (int)               版本，正常为 4
total element refs (int)
total frames (int)
total events (int)
Numanims (int)
  animname                  长度前缀字符串
  validfacings (byte)       xxxx dlur 位掩码
  rootsymbolhash (int)
  frame rate (float)
  num frames (int)
    x, y, w, h              float ×4
    num events (int)
      event hash (int)
    num elements (int)
      symbol hash (int)
      symbol frame (int)
      folder hash (int)
      mat a, b, c, d, tx, ty, tz   float ×7
num hashed strings (int)
  hash (int)
  original string           长度前缀字符串
```

## facing 位掩码

| 值 | 方向 |
|---|---|
| `1<<0` | 右 |
| `1<<1` | 上 |
| `1<<2` | 左 |
| `1<<3` | 下 |
| `1<<4` | 右上 |
| `1<<5` | 左上 |
| `1<<6` | 右下 |
| `1<<7` | 左下 |

## 字符串哈希

官方 `strhash`：

```python
hash = 0
for c in string:
    v = ord(c.lower())
    hash = (v + (hash << 6) + (hash << 16) - hash) & 0xFFFFFFFF
```

`build.bin` / `anim.bin` 里的 symbol、folder、event 名都存哈希，字符串表在文件末尾。
