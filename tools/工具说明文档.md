# tools —— 本机工具目录

存放 mod 开发用的脚本与第三方工具。**第三方二进制不入库**（`tools/app`、`tools/cli`、`tools/gui` 在 `.gitignore` 里），换机器时需要重新下载。

## 目录结构

```
tools/
├─ 工具说明文档.md         本文件
├─ 社区工具资料.md         ktools / Spriter / STex 等社区资料
├─ scripts/               自己写的 PowerShell 脚本（入库）
├─ app/                   GUI 程序（不入库）
├─ cli/                   命令行工具（不入库）
└─ gui/                   小工具（不入库）
```

## 本地脚本（`scripts/`）

| 脚本 | 用途 | 什么时候跑 |
|---|---|---|
| `check_changes.ps1` | 列出工作区新增/删除/修改，并按类别给出同步建议 | **每次提交前**，第一步 |
| `sync_annotated.ps1` | 把精简版 `.lua` 同步进 `setting/annotated/` | 改完代码后 |
| `check_docs.ps1` | 检查文档结构、链接、必备文件、工具路径 | 改完文档后 |
| `check_anim_duration.ps1` | 检查 mod 的动画时长/帧率是否符合预期 | 改动画后 |
| `prepare_refs.ps1` | 从游戏包解压 `refs/other_reference/scripts` | 换机器 / 游戏更新后 |
| `clean_scratch.ps1` | 清理 `_scratch/` 下的任务临时目录 | 每周 / 体积超限时 |

### 用法

在仓库根目录执行：

```powershell
# 改动盘点
powershell -ExecutionPolicy Bypass -File tools\scripts\check_changes.ps1

# 同步注释存档
powershell -ExecutionPolicy Bypass -File tools\scripts\sync_annotated.ps1

# 文档检查
powershell -ExecutionPolicy Bypass -File tools\scripts\check_docs.ps1

# 解压游戏源码（换机器时）
powershell -ExecutionPolicy Bypass -File tools\scripts\prepare_refs.ps1

# 清理临时目录
powershell -ExecutionPolicy Bypass -File tools\scripts\clean_scratch.ps1
```

## 第三方工具

### `app/` —— GUI 程序

| 程序 | 用途 |
|---|---|
| `DST Mod Tool.exe` | 动画/贴图编辑，scml、zip、tex 查看与打包 |
| `Asset Archive.exe` | DST 资源解包（anim、atlas、音频） |
| `Spriter.exe`（快捷方式） | 骨骼动画编辑，导出的 scml 供动画工具使用 |

### `cli/` —— 命令行

| 目录 | 用途 |
|---|---|
| `stex/` | `stex.exe`：PNG ↔ TEX，唯一能正确处理透明通道的工具 |
| `ktools/` | `krane`（bin → scml）、`ktech`（tex ↔ png）、`BuildRenamer`（改 build 名） |
| `animbuilder/` | `animc.exe` 编译 anim.xml/build.xml，`animd.exe` 反编译 |
| `pyscripts/` | `cli.py`：zip ↔ scml、build/anim 转换、图集打包；含中文说明 |
| `fsb-extractor/` | FSB 音频提取 |
| `steam/` | Steam 相关辅助 |

### `gui/` —— 小工具

| 目录 | 用途 |
|---|---|
| `bmfont/` | 位图字体制作（官方使用 v1.12a） |
| `fsbextractor/` | FSB 音频查看/提取 |
| `speech-editor/` | 语言文件（speech）编辑器 |

## 常用流程

### 提交前

```text
check_changes.ps1 → sync_annotated.ps1 → check_docs.ps1 → git add / commit
```

详细清单见 `docs/文档同步清单.md`。

### 换机器

```text
下载第三方工具到 app/ cli/ gui/
→ prepare_refs.ps1 解压游戏源码
→ 按 docs/本机环境.local.md 校正路径
```

### 动画相关

- 打包 scml：`tools\cli\pyscripts\cli.py <file.scml>`
- 解包 zip：`tools\cli\pyscripts\cli.py <file.zip>`
- 检查时长：`tools\scripts\check_anim_duration.ps1`
- 贴图转换：`tools\cli\stex\stex.exe compress / decompress`

## 维护约定

1. 新增**自己写的**脚本放 `scripts/`，并在上表登记用途与用法
2. 第三方工具放 `app/`、`cli/`、`gui/`，**不要提交**（体积大、有版权）
3. 新增第三方工具时，在本文件补一行说明和来源
4. 脚本移动位置后，同步更新 `docs/` 与 `README.md` 里的路径引用
