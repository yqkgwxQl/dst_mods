# AI 美术协作流程

> 适用：本 mod 的武器、图标、特效贴图，以及后续人物 mod 的美术资源。
>
> 前提：本机没有可用的本地 GPU 部署环境，使用**云端生图 + Photoshop 清理**。

## 一、工具分工

| 环节 | 工具 | 说明 |
|---|---|---|
| 概念 / 试配色 | 即梦、豆包 | 免费、中文提示词好，适合快速看效果 |
| 批量生产 / 可控生成 | LiblibAI、吐司（云端 SD） | 支持 ControlNet、局部重绘、LoRA |
| 强编辑 / 一致性 | Gemini 2.5 Flash Image、Qwen-Image-Edit | 多轮编辑、保持角色 |
| API 批量调用 | 硅基流动、阿里百炼、fal.ai | 按张计费，脚本化 |
| 收尾 | Photoshop | 抠图、补洞、统一画布、缩放 |

原则：**AI 负责“画”，人负责“选、修、定尺寸”**。不要把 AI 出的图直接放进 build。

## 二、风格圣经（每次生图前先看）

维护在 `setting/setting_description.md`，至少包含：

| 项 | 示例 |
|---|---|
| 主色 | 幽绿 `#3FD9B0`、暗青 `#1B3B35`、近黑 `#0E1512`、暗金 `#C9A227` |
| 线宽 | 最终 320 高时 3–4 px |
| 比例 | 武器约 1:4；人物 2.5–3 头身 |
| 材质 | 暗银金属 + 幽绿半透明 + 暗金点缀 |
| 参考图 | 官方美宣、上一版满意成品 |

## 三、提示词模板

### 1. 武器（通用）

```text
参考图中的<武器名>，重绘成《饥荒联机版》游戏道具素材。

【保留】剪影、比例、护手结构、配色、发光核心。
【简化】平涂 2–3 个色阶；护手雕花改大块面；裂纹只留 3–5 条粗的；描边加粗。
【配色】<十六进制色表>。
【构图】单把武器、竖直居中、正面平视、完整入画、剑尖朝上。
【背景】纯白 #FFFFFF，无阴影、无烟雾、无暗角。
【输出】512×2048，PNG，无文字、水印。
```

负面：

```text
不要：渐变、柔光、烟雾、灰雾、暗角、写实 3D、厚涂、细碎线条、人物、手、多把武器、文字、水印
```

### 2. 分件（武器 + 黑雾）

- 先出“只有武器”一张
- 再出“只有黑雾”一张
- 两张**同画布、同中轴**，方便叠加
- 不要把雾烘焙进武器贴图

### 3. 人物三视图

```text
同一个角色的正面、侧面、背面三视图，饥荒手绘风格，
平涂、粗墨线、2.5 头身，纯白背景，三张并排，比例一致。
```

### 4. 图标

```text
64×64 游戏物品图标，<物品>，饥荒手绘风，粗描边，纯色平涂，
主体占满画布 80%，纯白背景。
```

## 四、标准工作流

```text
1. 定需求（尺寸、用途、游戏内显示大小）
2. 找参考（官方图 / 上一版 / 真实照片）
3. 概念阶段：即梦/豆包出 8–12 张，只挑方向
4. 结构阶段：LiblibAI 用参考图 + ControlNet（lineart/pose）出 4 张
5. 细节阶段：局部重绘修护手/脸/裂纹
6. 挑选：按“剪影清楚、缩到 320 还可读”标准
7. PS 清理：抠图、去水印、补洞、统一画布
8. 缩放：剑身 320 高（2 倍余量）
9. 进游戏验证：大小、握持、昼夜观感
10. 归档：source/ + final/，记录提示词和 seed
```

## 五、文件规范

```text
assets/
├─ current/commit/        当前进游戏的成品
├─ old_version/vN/source/ 每轮 AI 原图
├─ old_version/vN/final/  处理后的成品
└─ README.md              版本说明
```

命名：

- 源图：`ai1.png`、`ai1_1.png`（分件）
- 成品：`ruined_blade_weapon_320.png`
- 预览：`preview_weapon.png`

记录：每轮至少保留 **提示词、模型、seed、参考图**，方便复现。

## 六、一致性策略

| 手段 | 适用 | 成本 |
|---|---|---|
| 参考图 + 提示词 | 单张、短期 | 低 |
| ControlNet 线稿/姿势 | 结构固定 | 中 |
| 局部重绘 | 修细节 | 低 |
| **训练 LoRA** | 成套素材、人物 | 中（几块钱、半小时） |

**长期做人物 mod，一定要训 LoRA**：15–25 张精选图，云端训练，之后所有生成都带同一风格。

## 七、人物 mod 的特殊流程

AI 直接出“可切件人物”几乎不可能，按这个顺序：

1. AI 出全身三视图
2. 描成干净线稿（PS/Blender）
3. ControlNet 线稿 + LoRA 上色
4. 手动按头/身/手/腿切件
5. 统一 pivot、比例、朝向
6. 进游戏调动画

已有的 `viego_base.glb` 可以渲染成标准三视图，比凭空画可靠。

## 八、API 协作

适合批量、可复现的生成：

```text
config.json（模型、尺寸、参考图目录）
  → gen_image.py
  → 调 API
  → 保存到 source/，文件名带时间戳和 seed
  → 记录 prompt / seed / 参数
```

推荐平台：硅基流动（便宜）、阿里百炼（Qwen-Image-Edit）、fal.ai（ControlNet/LoRA）。

注意：**API 不解决一致性和透明底**，仍需后处理。

## 九、验收清单

- [ ] 无烟雾/灰底/暗角

### 图标

### 人物

- [ ] 三视图比例一致
- [ ] 可切件（头/身/手/腿边界清楚）
- [ ] 配色与风格圣经一致
- [ ] pivot 对齐

## 十、常见坑

| 坑 | 原因 | 解决 |
|---|---|---|
| 护手少画/合并 | AI 偷懒 | 提示词强调数量；ControlNet 线稿 |
| 背景出现灰雾 | 提示词写了“黑雾” | 贴图不要雾，雾用游戏内 FX |
| 剑身太细 | 提示词只说“修长” | 明确“320 高时 18–22 px 宽” |
| 细节太密 | AI 过度刻画 | 要求“大块面、3–5 条裂纹” |
| 白边 | 白底抠图残留 | alpha 收缩 1 px |
| 尺寸不对 | 生成后直接缩 | 先裁内容再按剑身高度缩放 |
| 水印 | 平台自动加 | 按区域清除或裁剪 |
