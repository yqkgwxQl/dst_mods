## 怎么用

1. **GLB 用 Blender 打开**：`File → Import → glTF 2.0`。
   - 用正交相机从 正 / 侧 / 背 三个方向渲染，得到标准三视图；
   - 关材质或改单色，能看清剪影和体积；
   - 骨骼名在 Armature 里可见，方便理解结构。
2. **原画**：画脸、王冠、胸甲细节最清楚，比 3D 截图适合描。
3. **截图**：已关水印，可直接当构图参考。

## 做饥荒人物的注意点

- DST 是 **2D 骨骼切图**（Spriter），GLB 不能直接导入游戏。
- LoL 是 ~7.5 头身写实比例，DST 是 2.5–3 头身；**比例必须重画**。
- 要保留的识别特征：高肩甲、王冠、青绿长剑、破碎的黑雾披风。
- 版权：素材归 Riot Games；参考重绘可以，直接分发模型/贴图有下架风险。
