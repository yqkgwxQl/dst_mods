# 破败王者之刃 · 设定

> 一把来自暗影岛的诅咒之剑。它记得主人失去的一切，也要求持剑的人付出同样的代价。
>
> 出处：《英雄联盟》装备「破败王者之刃」（Blade of the Ruined King），持有者是破败之王·佛耶戈。

---

## 一、它是什么

| 项 | 内容 |
|---|---|
| 原作 | 《英雄联盟》中的一件传说级装备 |
| 持有者 | 佛耶戈（Viego），破败之王 |
| 在 DST 里的定位 | 单手剑，**中后期、暗影系、带诅咒**的武器 |
| 核心气质 | 深情到偏执、华美到腐朽、以他人的生命续自己的执念 |

一句话：**它不是一把“强”的剑，而是一把“要价”的剑——威力来自黑雾，代价来自理智。**

---

## 二、世界观

### 佛耶戈

卡玛维亚王国的二王子，本不该继承王位。他养尊处优、自私任性，对治国毫无兴趣；兄长意外死后，他被推上王位。

后来他遇见出身贫寒的裁缝女工**伊苏尔德**，不顾身份差距娶她为后。感情看似浓烈，但那份爱里始终带着强烈的占有欲与执念。

### 悲剧

一次针对佛耶戈的暗杀中，淬毒匕首没有击中他，却误伤了伊苏尔德。她毒发身亡，佛耶戈彻底崩溃——他耗尽王国财富寻找复活之法，国家因此陷入混乱。

### 破败之咒

他听说福光岛的“生命之水”能治愈一切，便率军入侵这座和平岛屿，把伊苏尔德的遗体浸入圣水。她短暂复苏，却化作充满痛苦与愤怒的怨灵，用佛耶戈自己的剑刺穿了他的心脏。

圣水与古剑的力量爆发，**福光岛就此化为暗影岛**，大量生命被扭曲成不死之物。

### 千年之后

佛耶戈以亡魂怨灵的形态苏醒，被称为破败之王。他操控黑雾与蚀魂夜，在符文之地四处搜寻伊苏尔德的灵魂碎片，试图把她完整地带回身边——不惜毁灭一切。

> 故事内核：一个自私而痴狂的国王，为了复活亡妻，毁掉了自己的王国、福光岛，乃至整个符文之地的安宁。

## 三、武器本身（原作属性）

### 数值

| 属性 | 数值 |
|---|---|
| 攻击力 | 40 |
| 攻击速度 | 25% |
| 生命偷取 | 10% |

### 特效

- **雾之锋**：普攻附带目标**当前生命值**的物理伤害——近战 9% / 远程 6%，对小兵与野怪最多 100 点。
- **抓挠之影**：对同一英雄命中 **3 次**后，触发 30% 减速。

### 合成

吸血鬼节杖（900）+ 反曲之弓（700）+ 十字镐（875）+ 725 卷轴，总计 3200 金币。

> 原作里它是「打坦神器」：百分比伤害对高血量目标压制极强。这一点在 DST 里**必须大幅削弱**，否则几刀就能磨死 BOSS。

## 四、视觉语言

从原画和武器图里能提炼出的、要在 DST 里保留的识别特征：

| 元素 | 描述 | 用途 |
|---|---|---|
| **青绿剑光** | 剑刃与裂纹里透出的荧光青绿，是整把武器的主色 | 武器本体、命中特效、夜晚微光 |
| **黑雾** | 缠绕剑身与角色的暗色雾带，边缘会散开 | 拖尾、击杀、破碎特效 |
| **破碎金饰** | 护手与剑柄上的暗金纹样，边缘残缺 | 图标、模型细节 |
| **王冠轮廓** | 剑柄末端收成王冠状 | 剪影识别点 |
| **裂纹** | 剑脊上的裂痕（“破败”的由来） | 低耐久状态、破碎演出 |

配色参考：主体青绿 `#3FD9B0` 左右，阴影黑紫 `#1A1420`，金饰 `#C9A227`。

## 六、从设定到机制

设定里能直接“翻译”成 DST 机制的钩子：

| 设定 | 机制落点 |
|---|---|
| 雾之锋：按当前生命值造成伤害 | 命中附加少量“当前生命百分比”伤害（有上限） |
| 抓挠之影：三击减速 | 同一目标叠 3 层印记 → 减速 + 黑雾爪痕 |
| 生命偷取 | 命中回少量血，击杀回更多 |
| 破败之咒：以理智为代价 | 装备时持续掉理智；低理智时反而更强 |
| 剑会“碎” | 耐久耗尽时掉 2 个噩梦燃料（黑雾爆散特效待做） |

详细数值与实现见 [mechanic_design.md](mechanic_design.md)。
