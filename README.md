## 包含的模组

### 破败王者之刃 · Blade of the Ruined King

`mods/blade_of_the_ruined_king`

一把来自《英雄联盟》的诅咒之剑：面板只比长矛略高，强度来自雾之锋的百分比真伤、三击减速和“越疯越强”的理智加成；代价是装备时持续掉理智。

| 项目 | 数值 |
|---|---|
| 类型 | 武器（WEAPONS 栏） |
| 伤害 | 54（低理智时最高 +25%） |
| 耐久 | 100 次 |
| 配方 | 噩梦燃料 ×2 + 金块 ×1 + 燧石 ×1 |
| 科技要求 | 炼金引擎 |
| 特性 | 雾之锋真伤、三击减速、命中/击杀吸血、低理智增伤、破碎掉 2 个噩梦燃料、可用噩梦燃料修理 |

机制一览：

- **雾之锋**：命中附加目标当前生命 3% 真伤，单次上限 20（目标血量上限 > 100 才触发）
- **抓挠之影**：同一目标 4 秒内叠满 3 击 → 减速 30%，持续 3 秒
- **生命偷取**：命中 +1，击杀再 +3
- **破败之咒**：装备时理智 -50/天；理智越低伤害越高
- **破碎**：耐久耗尽碎成 2 个噩梦燃料；用噩梦燃料可以修回来（每次 +50 耐久）

游戏内描述：

> 永失吾爱，举目破败

**状态**：P0 数值、P1 机制、P2 战斗特效已完成并通过验证；贴图已换成双十字护手版本。下一步做 P3 打磨（常驻剑雾、低耐久裂纹、夜晚发光）。详细设计与数值见 [mechanic_design.md](mods/blade_of_the_ruined_king/setting/mechanic_design.md)。

## 安装

**方式一：手动安装**

1. 把 `mods/` 下的模组文件夹整个复制到游戏的 mods 目录：
   - Windows：`<Steam 安装目录>\steamapps\common\Don't Starve Together\mods\`
2. 启动游戏 → 主菜单「模组」→ 找到对应模组 → 勾选启用
3. 新建或进入世界时，在「模组」选项卡里确认已启用

> 装到已有存档里可能影响平衡，建议先用新世界测试。

## 开发说明

本仓库同时是一套模组开发与测试环境，包含测试方法论和工具链。

```
.
├─ mods/     各个模组的源码（进仓库）
├─ docs/     测试手册、工具笔记（进仓库）
├─ refs/     游戏 Lua 源码与参考资料（不进仓库，可重建）
└─ tools/    开发工具（只提交 .ps1 脚本，其余为本地工具）
```

- **测试手册**：[docs/MOD测试手册.md](docs/MOD测试手册.md) —— 分层的测试方法与故障排查
- **工作区约定**：[docs/工作区约定.md](docs/工作区约定.md) —— 目录职责、临时文件规则、清理脚本
- **文档同步清单**：[docs/文档同步清单.md](docs/文档同步清单.md) —— 提交前核对所有文档与代码是否一致
- **重建参考资料**：`refs/` 未入库，clone 后执行

  ```powershell
  powershell -ExecutionPolicy Bypass -File .\tools\prepare_refs.ps1
  # 游戏装在非默认位置时：
  # .\tools\prepare_refs.ps1 -GameDir "D:\Games\Don't Starve Together"
  ```

  脚本从本机游戏的 `data/databundles/scripts.zip` 解压出约 4100 个 Lua 文件，供查 API 与参考原版实现使用。

- **让游戏读取仓库里的模组**（改完立即生效，无需复制）：

  ```
  mklink /J "<游戏目录>\mods\<模组名>" "<本仓库路径>\mods\<模组名>"
  ```

  删除联接用 `rmdir`，不要用 `Remove-Item -Recurse`——后者会顺着链接删掉仓库里的真实文件。
